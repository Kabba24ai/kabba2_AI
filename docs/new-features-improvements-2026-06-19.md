## New Features
- Added Dispatch Intelligence Rules to help automate and improve dispatch decisions.
- Introduced Equipment Intelligence Rules module for smarter equipment management.
- New Sales by Store report and filter to analyze sales performance by store location.
- Added Sales Trend report to track sales changes over time.
- AI-generated release notes are now available with a quick access shortcut in the admin navbar.
- Added Manual Value Entry modal in equipment matrix to easily input missing specification values.
- New Reset AI Specs button to re-enable category-wide specification research.
- Added Driver CDL (A/B) designation and capability settings for dispatch and HRM.
- Added Call Needed button for damaged equipment conflicts and supplier contacts in dashboard.
- Replaced native date input with a calendar picker in the reschedule workflow.
- New AI Policy tab to view and edit dispatch rules sent to ChatGPT.

## Improvements
- Updated product performance chart with clearer data visualization.
- Improved Sales Reports with new KPIs including Total Realized Revenue and COD payment status filters.
- Enhanced Dispatch AI with structured business rules and expanded response details.
- Updated dispatch driver and equipment rules UI with 3-column card grids for better usability.
- Improved matrix page with clickable missing presence icons and toggles for key comparison flags.
- Replaced separate search inputs in supplier dropdown with inline search and improved separator display.
- Improved schedule conflict detection to include soft-assigned double bookings.
- Performance and stability improvements in sales reports and pagination.
- Persist instant status changes on equipment matrix toggles.
- Unified Auto Assign rule sets and fixed related assignment bypass issues.
- Updated dashboard UI elements for better readability and color contrast.

## Fixes
- Fixed Schedule Assignment ignoring category filter in double booking resolution.
- Corrected badge count in Key Comparison Criteria after reset and regenerate.
- Fixed 405 errors in nested forms for truck and driver save actions.
- Resolved navigation issue where Resolve Damaged Booking now preselects the correct equipment.
- Fixed sales report CSS and error issues affecting display.
- Excluded Rescheduled Pending items from active schedules by default.

- Fixed toggle button styles and positions for better accessibility.

- Fixed sync problems with equipment and specification keys after updates.
