## New Features
- Added new Dispatch Intelligence Rules module to help automate and optimize dispatch decisions.
- Introduced Equipment Intelligence Rules module for improved equipment management insights.
- Added new Sales Reports: Sales by Store, Sales Trend, and Pure Sales Summary with additional KPIs and filters.
- Added filter by store option in sales reports for more precise data analysis.
- Introduced AI Policy tab enabling users to view and edit rules sent to ChatGPT for dispatch automation.
- Added Reset AI Specs button to re-enable category-wide specification research.
- Added Supplier as a new "Call Needed" contact type in Dashboard and Schedule Conflicts.
- Enabled manual value entry for specifications directly in equipment matrix cells.
- Replaced native date input with calendar picker in reschedule modal for easier date selection.

## Improvements
- Improved sales reports with clearer KPIs: Gross Sales defined as total realized revenue, added Tire Insurance, removed Shipping.
- Enhanced dispatch AI policy engine with structured business rules and expanded response schema for better decision guidance.
- Updated driver, truck, trailer, and equipment AI tabs with improved layouts matching across categories.
- Added multi-select hitch types and alphabetical sorting in dispatch AI equipment and trucks sections.
- Fixed dashboard conflict count and double booking detection to include soft-assigned orders for accurate scheduling views.
- Connected HRM CDL settings directly with Dispatch Driver Capabilities for a unified source of truth.
- Added Payment Status filter defaulting to "Paid" in sales reports.
- Added Supplier dropdown enhancements including inline search and better spacing for improved usability.
- Improved matrix tab with clickable icons linking to equipment specification pages.
- Updated specification profile with a Deep Research modal showing source URLs and follow-up correction options.
- Improved UI consistency and interaction, including toggle button colors and layout fixes for 3-column grids in dispatch AI tabs.
- Various internal performance and UI fixes across sales reports, dispatch, and scheduling modules.

## Fixes
- Fixed Schedule Assignment to respect category filter in resolving double bookings.
- Corrected sales report CSS and pagination issues for better display and navigation.
- Fixed server errors (500, 405) related to nested forms and missing route references.
- Resolved issue excluding Rescheduled Pending items incorrectly from active schedules.
- Fixed Key Comparison Criteria badge count mismatches after resets.
- Corrected "Resolve Damaged Booking" button behavior to preselect equipment on navigation.
- Fixed toggle thumb positioning and dispatch AI rules toggle behavior.
- Fixed filters JS loading in sales report pages.

## What to Expect
- New dispatch and equipment intelligence modules will provide rule-based automation options you can configure.
- Sales reports now include more detailed filters and KPIs, plus new reports by store and sales trends.
- You can now manually enter equipment specification values and access detailed AI research on specs.
- Rescheduling dates can be chosen with an improved calendar picker.
- Schedule conflicts and dashboard counts are more accurate, including soft assignments.
- Some user interface elements in dispatch AI and sales reports have updated layouts and more responsive filters.
- "Call Needed" contacts now include suppliers for better communication tracking.

## Action Needed

- Explore new sales reports and filters to better analyze store and trend performance.
